# 05 · DaVinci Resolve 调色流程

结论先说：Resolve 调色的标准流程就 5 步——建项目、套 LUT、调曝光白平衡、风格微调、输出。节点顺序是曝光修正 → LUT → 微调，别乱。

Resolve 免费版就能完成本指南的全部流程。下载：Blackmagic 官网 → DaVinci Resolve → 免费下载，Windows / Mac 都有。安装时选免费版，不用注册付费。

## 第一步：建项目，设好色彩管理

1. 打开 Resolve → 新建项目 → 名字随便起。
2. 项目设置（右下角齿轮）→ 色彩管理：
   - 色彩科学：DaVinci YRGB（默认就行，别选 DaVinci Wide Gamut，新手没必要）。
   - 时间线色彩空间：Rec.709 Gamma 2.4（发手机、发社交平台的标准）。
   - 输出色彩空间：Rec.709 Gamma 2.4。
3. 时间线分辨率：4K 素材就建 4K 时间线（3840×2160）；只想发短视频、电脑配置一般，建 1080p 时间线也行，4K 素材放进去还能二次构图（放大裁切不损失画质）。

为什么时间线设 Rec.709：本仓库的 LUT 输出就是 Rec.709，时间线和 LUT 输出一致，看到什么就是什么，不用再转一遍。

## 第二步：导入素材，粗剪

1. 媒体页面（底部第一个图标）→ 把 iPhone 拍的视频拖进来。
2. 剪辑页面（底部第二个图标）→ 把素材拖到时间线，按顺序排好，剪掉不要的部分。
3. 先剪辑、后调色。调色是最后一步，别在还没剪好的素材上调色，白费功夫。

iPhone 素材传到电脑：隔空投送（Mac）、数据线 + iTunes 文件共享、iCloud 云盘，或者直接用硬盘 U 盘拷。ProRes 文件很大，优先用数据线或硬盘，别用微信传（会压缩）。

## 第三步：节点顺序（核心）

切到调色页面（底部第四个图标，调色盘图标）。每个素材默认有一个节点，右键 → 添加节点，可以加多个。推荐的节点结构：

| 节点 | 做什么 | 具体操作 |
|---|---|---|
| 节点 1：修正 | 曝光、白平衡 | 曝光往亮/暗调 0.3–1 档；色温修准（偏黄降色温，偏蓝升色温） |
| 节点 2：LUT | 套 LUT | 右键节点 → 3D LUT → 选 `.cube` 文件 |
| 节点 3：微调 | 饱和、对比、暗部 | 饱和 ±10–15；需要的话用曲线微调暗部 |
| 节点 4：风格（可选） | 颗粒、暗角、光晕 | 按需添加，别贪多 |

**为什么这个顺序**：

- 曝光和白平衡必须在 LUT 之前修。LUT 是按“曝光正确、白平衡正确”的 Log 素材设计的，素材本身偏了，LUT 的输出也会偏。
- 饱和和对比在 LUT 之后调。LUT 已经把风格定好了，之后只需要小幅修正，不用大动。
- 每个节点只做一件事。想改就只动对应节点，不用全盘重来。节点名可以双击改名（比如“曝光修正”“Gold LUT”“饱和微调”），养成习惯，项目大了不乱。

## 第四步：具体调法（按节点）

**节点 1：曝光和白平衡**

- 看波形图（Scopes，调色页面右上角）：亮部别顶到 100 IRE 以上（死白），暗部别压到 0 以下（死黑）。Log 素材的波形本来集中在中间，套 LUT 之前先把整体亮度调到舒服的位置。
- 白平衡：用色温滑杆，或者点白平衡吸管工具吸画面里的白色/灰色物体（白墙、白纸、灰色衣服）。没有白色物体就手动滑，看着顺眼就行。
- 曝光参考值：向右曝光拍的素材，这里通常要往下压 0.3–0.7 档；正常曝光的素材基本不用动。

**节点 2：套 LUT**

- 右键节点 → 3D LUT → 选择本仓库的 `.cube` 文件。
- 或者把 `.cube` 文件放进 Resolve 的 LUT 文件夹：偏好设置 → 媒体存储 → 找到 LUT 文件夹路径 → 把文件拷进去 → 重启 Resolve → 调色页面左侧 LUT 面板里直接点。
- 套完觉得太浓：选中 LUT 节点 → 右键 → 调整节点 Key Output 的 Gain（降到 0.7–0.85），等于把 LUT 强度降下来。
- 同一个项目里，同一场景的素材用同一个 LUT、同一个强度。

**节点 3：微调**

- 饱和：色轮面板下面的饱和度滑杆，±10–15 就够了。别拉太多，手机传感器拍的素材饱和拉过头会断层。
- 对比：觉得画面太平，在曲线面板里拉一个轻微的 S 曲线（暗部往下压一点、亮部往上提一点）。注意别和 LUT 的对比叠加过头。
- 肤色：拍人像的话，用限定器（Qualifier）单独选肤色，微调饱和和亮度。Portra 本来就对肤色友好，通常不用单独调。

**节点 4：风格（可选，别贪多）**

- 胶片颗粒：效果 → 颗粒，可以加一点（强度 0.2–0.4），增加胶片感。加多了显脏，手机小屏幕上 0.3 就够了。
- 暗角：效果 → 暗角，轻微压暗四角，引导视线到画面中心。强度别超过 0.5。
- 黑边：想做出电影感的 2.39:1 宽画幅，时间线设置里改分辨率，或者在调色页面加 Letterbox。注意黑边是上下裁切，会损失一部分画面，构图时要预留。

## 第五步：输出设置

调完色，切到交付页面（底部最后一个图标，火箭图标）。

| 输出目标 | 设置 |
|---|---|
| 发 TikTok / 抖音 / 小红书 | 格式 MP4，编码 H.264 或 H.265，分辨率 1080×1920（竖屏）或 3840×2160（横屏 4K），帧率和时间线一致，码率 15000–25000 kbps |
| 发 YouTube / B 站 | 格式 MP4，编码 H.264，分辨率 3840×2160，帧率和时间线一致，码率 35000–45000 kbps |
| 存档 / 以后还要剪 | 格式 QuickTime，编码 ProRes 422，码率自动 |

关键设置：

- **分辨率**：输出分辨率别超过时间线分辨率。1080p 时间线输出 4K 是假 4K，没意义。
- **帧率**：和时间线一致，别改。24fps 时间线输出 30fps 会有卡顿感。
- **码率**：发社交平台别太低，平台还会再压一次。源文件码率低 + 平台二次压缩 = 糊。宁可文件大一点。
- **色彩空间标签**：输出时确认是 Rec.709，别输出成 Rec.2020 或 HDR，手机上看会偏色。

输出前检查：从头到尾放一遍成片，看有没有跳帧、偏色、音频问题。确认无误再点“加入渲染队列”→“全部渲染”。

## 批量调色：省时间的办法

- **复制调色**：调好一个镜头，右键 → 复制，再选中其他同场景的镜头 → 粘贴。或者用“应用调色”批量套。
- **共享节点**：把 LUT 节点存为共享节点（右键 → 保存为共享节点），其他素材直接调用，改一次全片都改。
- **调色预设**：调好一套节点结构，右键时间线缩略图 → 保存为静帧（Grab Still），以后右键静帧 → 应用调色，一键复用。
- **分组调色**：同一场景的镜头分到一个组，组级别套 LUT，组内镜头再单独微调。适合多机位、多镜头的项目。
