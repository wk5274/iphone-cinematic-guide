# 04 · LUT 工作流：从监看到成片

结论先说：LUT 分两种——监看 LUT 只给你看，不动素材；输出 LUT 是调色的起点，套完还要微调。搞混这两种，是新手最常见的坑。

## 监看 LUT vs 输出 LUT

| | 监看 LUT | 输出 LUT |
|---|---|---|
| 作用 | 拍摄时让灰蒙蒙的 Log 画面看起来正常，方便判断曝光和构图 | 后期调色时把 Log 转成 Rec.709 并赋予风格 |
| 影响素材吗 | 不影响，录下来的还是 Log 原片 | 是调色的一部分，会进最终成片 |
| 在哪用 | Blackmagic Cam 取景时 | DaVinci Resolve / Premiere / Final Cut 里 |
| 本仓库的 LUT 能当哪种 | 两种都能当 | 两种都能当 |

本仓库的 9 个 LUT 是“一步到位”型：既做 Log→Rec.709 的转换，也带风格。所以同一个文件，拍摄时当监看 LUT、后期当输出 LUT，效果是一致的——你在取景器里看到什么样，套完就是什么样，不用猜。

唯一要注意的：Blackmagic Cam 里有个“将 LUT 烧录进视频”的选项，**永远不要开**。烧录了，录下来的就是带风格的 Rec.709，Log 的宽容度全丢了，等于白拍 Log。监看就只是监看，别烧录。

## Blackmagic Cam 里导入监看 LUT

1. 把 `.cube` 文件传到 iPhone，存进“文件”App（隔空投送、iCloud、数据线都行）。
2. Blackmagic Cam → 设置 → LUT → 导入 LUT → 选文件。
3. 9 个全导进去，拍摄时在 LUT 列表里轮着切。
4. 拍完检查：回放素材应该是灰的（Log 原片）。如果回放就是彩色的，说明你不小心开了烧录，赶紧关掉重拍。

## DaVinci Resolve 里套 LUT

Resolve 是调色的标准工具，免费版就够用（Studio 付费版多了降噪、AI 工具等，调色本身免费版全有）。

**方法一：节点上套（推荐）**

1. 剪辑页面把素材放上时间线，切换到调色页面。
2. 选中素材，右键节点 → 3D LUT → 选 `.cube` 文件。或者先把 `.cube` 文件放进 Resolve 的 LUT 文件夹（偏好设置 → 媒体存储 → LUT 文件夹位置），重启后在 LUT 面板里直接点。
3. LUT 放在一个单独的节点里，不要和曝光、白平衡的调整混在一个节点。这样想换 LUT、想调强度，都只动这一个节点。

**方法二：时间线级套**

整条时间线统一套一个 LUT：调色页面 → 时间线节点（选中时间线）→ 套 LUT。适合一镜到底、光线统一的短片。光线变化大的片子还是逐个镜头套。

**节点顺序（重要）**：曝光 / 白平衡修正 → LUT 节点 → 风格微调节点。LUT 之前先把曝光和白平衡修准，LUT 之后再做精细调整。详细流程见 [05 Resolve 调色流程](05-davinci-resolve-grading.md)。

## Premiere Pro 里套 LUT

1. 选中素材 → 打开 Lumetri 颜色面板。
2. 创意 → 浏览 → 选 `.cube` 文件。
3. 创意面板里有“强度”滑杆，可以把 LUT 效果从 100% 往下减（见下面微调部分）。
4. 也可以在基本校正里先调曝光和白平衡，再到创意里套 LUT，顺序和 Resolve 一样：先修正、再套 LUT、再微调。

Premiere 的 Lumetri 颜色面板自带输入 LUT 选项（基本校正 → 输入 LUT），但那是给“技术型转换 LUT”准备的。本仓库的 LUT 带风格，建议走创意面板，不走输入 LUT。

## Final Cut Pro 里套 LUT

1. 选中素材 → 效果 → 颜色 → 自定 LUT。
2. 在检查器里点 LUT 下拉菜单 → 选取自定 LUT → 选 `.cube` 文件。
3. 混合滑杆可以调强度。

Final Cut 的自定 LUT 效果可以直接拖到多个素材上，批量套用很方便。注意 FCP 会把 LUT 文件复制一份存进资源库，换电脑打开工程不会丢 LUT。

## 套完怎么微调

LUT 是起点，不是终点。每段素材的光线都不一样，套完 LUT 通常还要调这 4 样：

**1. 强度（最常用）**

LUT 效果太浓了？把强度降到 70%–85%，立刻自然很多。Resolve 里调节点的不透明度（Key Output 的 Gain），Premiere 里调创意面板的强度滑杆，FCP 里调混合滑杆。

经验值：人像和日常，强度 75%–90% 最舒服；风景和大片感，可以 100% 拉满；Noir 和 BleachBypass 这类风格强的，降到 80% 左右更耐看。

**2. 曝光**

套完 LUT 觉得整体偏暗或偏亮，在 LUT 之前的节点里调曝光（不是 LUT 之后）。LUT 之前调曝光，LUT 的响应是线性的、干净的；LUT 之后调曝光，等于在已经定型的画面上硬拉，容易断层。

**3. 白平衡**

套完 LUT 觉得偏黄或偏蓝，在 LUT 之前的节点里调色温。先修准白平衡再套 LUT 是正道；如果已经套了才发现偏色，回到 LUT 之前的节点修，别在 LUT 之后硬掰。

**4. 饱和**

套完觉得颜色太艳或太淡，在 LUT 之后的节点里微调饱和 ±10–15 就够了。Ektar 本来就艳，觉得过了就降 10；Portra 本来就淡，觉得平了就加 10。

**4. 饱和**

套完觉得颜色太艳或太淡，在 LUT 之后的节点里微调饱和 ±10–15 就够了。Ektar 本来就艳，觉得过了就降 10；Portra 本来就淡，觉得平了就加 10。

## 各 LUT 强度参考

不是每个 LUT 都适合 100% 拉满。参考值：

| LUT | 推荐强度 | 说明 |
|---|---|---|
| Gold v2 | 85%–100% | 最居中，100% 通常没问题 |
| Portra v2 | 90%–100% | 本来就淡，降太多等于没套 |
| Ektar v2 | 75%–90% | 本来就艳，100% 容易过，尤其拍人时 |
| TealOrange | 80%–100% | 橙青对撞很强，日常场景降到 85% 更自然 |
| BleachBypass | 80%–100% | 低饱和是风格，降太多会变回普通片 |
| Noir | 75%–90% | 暗部很沉，100% 在室内容易死黑 |
| WarmVintage | 85%–100% | 褪色感是风格，强度低了褪色感就没了 |
| 709 两版 | 85%–100% | 偏冷偏暗，暗场景可以降到 85% |

记住那条经验：降到你觉得“刚好”的那个点，再往下降 5%。人眼对调色后的画面会快速适应，刚调完觉得正好，过 10 分钟再看往往觉得浓了。

## 多镜头统一调色

一个项目里有几十个镜头，一个个套 LUT 太慢了。用批量方法：

- **Resolve**：调好一个镜头 → 右键 → 复制 → 选中同场景的其他镜头 → 粘贴。或者把 LUT 节点存为共享节点，改一次全片都改。详细见 [05 Resolve 调色流程](05-davinci-resolve-grading.md)的批量调色部分。
- **Premiere**：把调好的 Lumetri 效果存为预设，拖到其他素材上。或者建一个调整图层，整段套同一个 LUT。
- **Final Cut**：把自定 LUT 效果拖到多个素材上，或者复制粘贴效果属性。

批量套完之后，每个镜头还是要单独检查曝光：同一场景不同镜头的曝光可能差半档，批量套 LUT 不会自动修正曝光。

## 导出前检查清单

1. 每个镜头都套上 LUT 了吗（有没有漏网的灰镜头）
2. 同一场景的 LUT 和强度一致吗
3. 有没有镜头过曝死白、死黑（看波形图）
4. 肤色正常吗（别黄得像生病、别红得像喝醉）
5. 从头到尾放一遍，有没有哪个镜头色彩突然跳变

## 一个镜头一个 LUT，还是全片一个 LUT

- **短片、Vlog、旅行片**：全片统一一个 LUT，风格一致，观众看着舒服。换场景也不换 LUT，只微调曝光和白平衡。
- **情绪变化大的片子**：可以按段落换 LUT。比如白天 Gold、夜晚 Noir，情绪转折的地方换 LUT 是成立的，但别一个镜头换一个，那样像滤镜大杂烩。
- **同一场景多机位**：必须同一个 LUT，否则切机位的时候色彩跳变，观众立刻出戏。

## 常见问题

**套完 LUT 画面发灰？** 先确认素材是 Apple Log 2（不是一代 Log、不是普通视频），再确认黑位——第一版 Gold v1 黑位 0.104 会发灰，已废弃，别用。现行 9 版黑位都在 0.081 以下，室内欠曝一档也验证过。还发灰的话，检查曝光是不是欠了 1 档以上：欠曝的 Log 素材套什么 LUT 都灰。

**套完 LUT 偏色？** 90% 是白平衡没锁。回到 LUT 之前的节点，把色温修准再看。

**LUT 强度怎么调最自然？** 降到你觉得“刚好”的那个点，再往下降 5%。人眼对调色后的画面会快速适应，刚调完觉得正好，过 10 分钟再看往往觉得浓了。
