# 03 · 拍摄技巧：曝光、构图、运镜、光线

结论先说：电影感 70% 在拍摄时就决定了，调色只能锦上添花。曝光准、构图稳、运镜慢、光线对，这四件事做好了，套哪个 LUT 都好看；这四件事没做好，什么 LUT 都救不回来。

## 曝光：准比亮重要

- 用向右曝光（ETTR），但别过曝。直方图靠右、斑马纹只出现在小高光点上，这是标准状态。详细原理见 [02 Apple Log 2 讲透](02-apple-log2-explained.md)。
- **锁定曝光再开拍**。Blackmagic Cam 里点一下锁定曝光，别让它在拍摄过程中自己漂。同一镜头里亮度忽明忽暗，后期没法修。
- 大光比场景（逆光、窗边、落日）优先保高光：高光一旦死白，信息全丢；暗部欠一点，后期还能提回来 1–2 档。
- 室内拍人脸：让人脸的亮度落在直方图中间偏右。人脸是观众第一眼看的地方，人脸曝光对了，整条片子就对了一半。

## 构图：先守规矩，再谈创意

**三分法**：打开取景网格线，把主体放在三分线的交点上，地平线放在上三分线或下三分线，别放正中间。这是零失败的构图，拍 100 条都不会错。

**前景、中景、背景三层**：画面里有前景（比如一片叶子、一扇窗框）、中景（主体）、背景（环境），立刻就有纵深感。手机传感器小、景深深，画面容易拍平，三层构图是补救办法。

**引导线**：路、桥、栏杆、光影的边界，都能当引导线，把视线引向主体。拍城市、拍建筑时多找找线。

**留白和呼吸感**：主体别塞满画面。拍人走路，前进方向多留一点空间；拍人说话，视线方向多留一点空间。画面太满会让人喘不过气。

**低角度显气势，高角度显孤独**：蹲下来贴地拍，人和建筑会显得高大；从高处往下拍，人物会显得渺小。换角度是最便宜的“电影感”。

**新手最容易犯的构图错误**：地平线歪了。打开水平仪（Blackmagic Cam 取景界面有），地平线歪 1° 观众都看得出来。拍完再裁掉歪的部分，等于白白损失画幅。

## 运镜：慢、稳、少

手机拍摄的运镜就三条铁律：

1. **慢**：推、拉、摇、移，速度都放慢一半。手机运镜一快就显廉价，慢下来立刻有电影感。一个镜头至少拍 5 秒，10 秒更好，后期剪的时候有余地。
2. **稳**：双手握持、手肘贴紧身体、走路时膝盖微屈做缓冲。或者直接上稳定器（见下面配件部分）。
3. **少**：一个镜头只做一个动作——要么推近、要么横移、要么摇，别又推又摇又移。复杂的运镜留给稳定器和后期。

几个好用的基础运镜：

| 运镜 | 做法 | 适合 |
|---|---|---|
| 固定镜头 | 手机架在三脚架上不动，让画面里的人和物自己动 | 对话、风景、延时感 |
| 缓推 | 慢慢向主体靠近，或者后期做数字推近 | 揭示、强调、情绪推进 |
| 横移 | 平行于主体匀速移动 | 跟拍行走的人、展示空间 |
| 环绕 | 以主体为圆心慢慢绕半圈 | 人像、产品、仪式感 |
| 升降 | 从低到高或从高到低匀速移动 | 揭示场景、转场 |

**转场别用花哨的**：闪白、旋转、缩放这些转场特效是新手标志。电影感的转场就三种：硬切（直接切）、叠化（淡入淡出）、遮挡转场（用一个前景物体挡一下镜头再切）。遮挡转场在手机上特别好做：路过一根柱子、一棵树、一面墙的时候切镜头，自然又高级。

## 光线：比设备重要 10 倍

- **黄金时段**：日出后一小时、日落前一小时，光线是暖的、斜的、柔和的，自带电影感。同一个地方，黄金时段拍和中午拍，是两个世界。能约黄金时段就别约中午。
- **中午顶光最难拍**：阴影生硬、人脸全是黑眼圈。非要中午拍，就找阴影（树荫、屋檐、室内窗边），别让人站在大太阳底下。
- **逆光拍轮廓**：让光从主体后面打过来，拍出轮廓光和光晕，Log 的宽容度就是为这种场景准备的。记得保高光，别让天空死白。
- **室内找窗光**：窗户是最好的柔光箱。让人侧对窗户，一边亮一边暗，立体感立刻出来。别让人背对窗户（脸全黑），也别正对窗户（脸太平）。
- **夜景找点光源**：霓虹灯、路灯、店招、车灯，夜景里有几个亮点，画面就有层次。全黑的环境拍什么都是黑的，Log 也救不了。

## 稳定器：要不要买

- **日常、旅行、短视频**：不用买。双手握稳 + 膝盖缓冲 + 后期轻微防抖就够了。iPhone 自带的光学防抖和电子防抖已经很强。
- **要拍运镜、跟拍、行走镜头**：买一个三轴手机稳定器。几百块的入门款就够用，别一上来买上千的。稳定器最大的价值不是“稳”，而是让你能做出匀速、顺滑的运镜。
- **拍延时、固定机位**：买个小三脚架 + 手机夹，几十块。延时摄影必须固定机位，手持拍延时等于白拍。

## 常见错误清单

| 错误 | 后果 | 改正 |
|---|---|---|
| 快门角度不对（太快） | 画面发干、发涩，像监控 | 锁 180°，见 [01 设置攻略](01-blackmagic-cam-setup.md) |
| 自动白平衡没锁 | 同一镜头色温来回跳 | 手动锁色温 |
| 运镜太快、太多 | 廉价感、看得头晕 | 慢一半，一个镜头一个动作 |
| 地平线歪了 | 业余感立刻拉满 | 开水平仪 |
| 逆光人脸死黑 | 主体看不清 | 向右曝光 + 后期提暗部，或补光 |
| 一个镜头只拍 2 秒 | 后期没法剪 | 每个镜头至少 5 秒 |
| 镜头有指纹 | 画面发雾、眩光 | 开拍前擦镜头，养成习惯 |
| 变焦用数码变焦 | 画质断崖下跌 | 只用 1x / 2x / 5x 光学焦段，数码变焦别碰 |
