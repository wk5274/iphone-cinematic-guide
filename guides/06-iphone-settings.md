# 06 · iPhone 拍摄设置清单

结论先说：拍 Log 之前，iPhone 里就改 3 个地方——格式开 ProRes、视频录制选 4K、存储留够空间。配件只买 3 样：ND 镜、三脚架、外置 SSD。其他的都是锦上添花。

## 机型要求

| 机型 | 能拍 Apple Log 2 吗 | 说明 |
|---|---|---|
| iPhone 15 Pro / 15 Pro Max | ✅ | 第一代支持 Log 的 iPhone |
| iPhone 16 Pro / 16 Pro Max | ✅ | 支持，新增相机控制按钮 |
| iPhone 17 Pro / 17 Pro Max | ✅ | 本指南实测机型 |
| iPhone 15 / 16 / 17（非 Pro） | ❌ | 没有 Log 功能 |
| iPhone 14 Pro 及之前 | ❌ | 硬件不支持 |

非 Pro 机型没有 Log，别折腾第三方 App 绕过——绕不过，硬件层面就没有这个能力。非 Pro 机型想拍电影感，用普通视频 + 后期调色，或者换 Pro 机型。

## iPhone 系统设置（拍之前改好）

**设置 → 相机 → 格式**

- 选“高效”（HEIF/HEVC）还是“兼容性最好”（JPEG/H.264）：拍视频的话这个选项主要影响照片格式，视频格式看下面。
- 打开 ProRes 开关（Pro 机型才有）。不开 ProRes，系统相机拍不了 Log。

**设置 → 相机 → 录制视频**

- 分辨率选 4K，帧率选 30fps（通用）或 24fps（电影感）。
- 注意：这里改的是系统相机 App 的设置，Blackmagic Cam 有自己独立的设置（见 [01 Blackmagic Cam 设置全攻略](01-blackmagic-cam-setup.md)），两边不互通。

**设置 → 相机 → 保留设置**

- 打开“保留相机模式”和“保留创意控制”。这样每次打开相机 App，不用重新选一遍模式和设置。

**设置 → 通用 → iPhone 存储空间**

- 拍 Log 之前先看剩余空间。4K ProRes 一分钟约 6GB，H.265 一分钟约 400MB。空间不够就先清，或者直接录到外置 SSD。

## Blackmagic Cam 还是系统相机

| | Blackmagic Cam | 系统相机 App |
|---|---|---|
| Log 格式 | Apple Log 2，可选 | Apple Log 2（ProRes 开关打开后） |
| 手动控制 | 全手动：ISO、快门角度、白平衡、焦点 | 有限手动（曝光锁定、白平衡锁定） |
| 监看 LUT | 支持导入 | 不支持 |
| 直方图 / 斑马纹 | 有 | 没有 |
| 外置 SSD 录制 | 支持 | 支持（ProRes 模式下） |
| 上手难度 | 需要学习 | 打开就能拍 |

结论：认真拍片子用 Blackmagic Cam，随手记录用系统相机。本仓库的 LUT 两种方式拍的 Log 素材都能用，只要确认是 Apple Log 2。

## 存储：算好账再出门

| 格式 | 1 分钟约占空间 | 256G 能拍多久 | 建议 |
|---|---|---|---|
| 4K 30fps H.265 | 约 400MB | 约 10 小时 | 日常、旅行，够用 |
| 4K 30fps ProRes 422 | 约 6GB | 约 40 分钟 | 必须外置 SSD |
| 4K 60fps ProRes 422 | 约 12GB | 约 20 分钟 | 必须外置 SSD |
| 1080p 30fps H.265 | 约 200MB | 约 20 小时 | 备用、空间紧张时 |

实拍建议：出门拍一天，H.265 的话 256G 够用；ProRes 的话必须带外置 SSD（1TB 起步），并且带个充电宝——ProRes 录制 + 外置硬盘，耗电比平时快 2–3 倍。

## 配件推荐（只写品类，不写购买链接）

**必买 3 样**：

1. **ND 减光镜（手机夹式）**：室外大太阳下，快门 180° + 最低 ISO 还是过曝，ND 镜是唯一解。ND8（减 3 档）和 ND64（减 6 档）各一个，基本覆盖所有室外场景。买夹式的，不用换手机壳。
2. **小三脚架 + 手机夹**：拍延时、固定机位、夜景长曝光必备。几十块的桌面小三脚架就够，户外用 1 米左右的便携三脚架。
3. **外置 SSD（USB-C，1TB 起步）**：拍 ProRes 必备。选 USB-C 接口、读取速度 1000MB/s 以上的，录制不掉帧。顺便当备份盘用。

**看需求买**：

- **三轴手机稳定器**：经常拍运镜、跟拍、边走边拍再买。几百块的入门款够用。只拍固定机位和短视频，不用买。
- **手机兔笼**：想挂麦克风、补光灯、ND 镜再买。裸机拍摄不需要。
- **无线麦克风**：拍 Vlog、采访、对话必备。只拍画面、不录人声，不用买。
- **补光灯（口袋 LED）**：夜景、室内弱光拍人像有用。户外白天用不上。
- **充电宝（10000mAh 以上）**：拍 ProRes + 外置 SSD 时耗电快，半天就没电。长时间外拍必带。

**不用买**：

- **手机外接镜头（广角/长焦附加镜）**：iPhone 自带的三摄已经覆盖 0.5x / 1x / 2x / 5x，附加镜头的画质不如原生镜头，还容易进灰、偏色。
- **手机散热器**：4K ProRes 长时间录制确实会发热，但正常拍摄（每次录 5–10 分钟）不会热到停机。除非你要连续录半小时以上，否则不用买。

## 不同预算的配件方案

| 预算 | 买什么 | 能拍什么 |
|---|---|---|
| 0 元 | 什么都不买，只用手机 + Blackmagic Cam | 日常、旅行、短视频、白天室外。90% 的场景够用了 |
| 约 500 元 | ND 镜（ND8 + ND64）+ 小三脚架 + 手机夹 | 加上：室外大太阳下的 180° 快门、延时、固定机位夜景 |
| 约 2000 元 | 上面全部 + 外置 SSD 1TB + 三轴稳定器 | 加上：ProRes 录制、运镜、跟拍、行走镜头 |
| 约 4000 元 | 上面全部 + 无线麦克风 + 口袋补光灯 + 兔笼 | 加上：Vlog、采访、对话、弱光人像 |

建议：先 0 元拍一个月，确定自己真的喜欢、真的坚持拍，再按需往上加。很多配件买回来吃灰，不是因为不好，是因为拍摄习惯还没养成。

## 存储管理技巧

- **拍完当天就导出来**：素材别在手机里攒着。每天拍完导到电脑或移动硬盘，手机里只留最近几天的。
- **用“优化 iPhone 存储空间”**：设置 → 照片 → 优化 iPhone 存储空间，照片原图存 iCloud、手机只留缩略图。注意：视频原图也在 iCloud 的话，剪辑时要先下载回本地，别在没网的地方剪。
- **传到电脑的几种方式**：
  - 隔空投送（Mac）：最方便，速度还行，适合 H.265 素材。
  - 数据线 + 访达/iTunes（Mac/Windows）：最稳，ProRes 大文件首选。
  - 外置 SSD 直录：拍的时候就录在硬盘上，拍完拔下来插电脑就能剪，零传输时间。
  - iCloud 云盘：能用，但上传大文件慢，还占 iCloud 空间，不推荐传视频。
- **别用微信/QQ 传素材**：会压缩画质，Log 素材传完就废了。必须用原文件传输的方式。

## 电池与发热

- **4K ProRes + 外置 SSD 录制，耗电是平时的 2–3 倍**。满电出门，半天就没电。长时间外拍必须带充电宝（10000mAh 以上），并且边拍边充。
- **发热是正常的**：4K 录制 + 夏天太阳直射，手机会发热。轻微发热不用管，继续拍；烫到握不住、屏幕变暗、弹出高温警告，就停下来歇 5 分钟，摘掉手机壳、放阴凉处。
- **降低发热的办法**：不用 ProRes 就用 H.265（编码压力小很多）；关掉不需要的后台 App；屏幕亮度别拉满；避免太阳直射手机背面。
- **低温也要注意**：冬天零度以下户外拍摄，电池掉电会变快。手机放内兜里保暖，拍的时候再拿出来。

## 出门拍摄检查清单

1. 存储空间够吗（ProRes 检查外置 SSD）
2. 电量满吗（充电宝带了吗）
3. 镜头擦干净了吗
4. Blackmagic Cam 设置对吗（Log 2、180°、手动白平衡、监看 LUT）
5. ND 镜带了吗（室外拍摄）
6. 三脚架 / 稳定器带了吗（按拍摄计划）
7. 麦克风带了吗（要录人声的话）
